# Project Roadmap

This roadmap outlines the planned features, enhancements, and goals for this personal GitHub profile repository. It aims to make the profile the best representation of my skills, projects, and activities.

## Short-Term Goals
- [ ] Add an `assets` directory to host local images and ensure all image filenames use CamelCase or hyphens (avoiding spaces) for consistent rendering across devices.
- [ ] Create a `language_separator.py` utility script using regex and Unicode ranges to address mixed Arabic and French text in product and category names, separating them cleanly.
- [ ] Implement a GitHub Actions workflow to automatically fetch and display the latest blog posts or recent GitHub activity directly on the `README.md`.

## Mid-Term Goals
- [ ] Expand the "About Me" section with more detailed information about my educational background, Infrastructures, Development, and Big Data processing studies.
- [ ] Add a "Portfolio Projects" section to showcase key repositories, pro bono consulting work, and open-source contributions.
- [ ] Incorporate dynamic status badges to highlight current learning tracks (Artificial Intelligence, Systems Design, Cloud Architecture).

## Long-Term Goals
- [ ] Set up automated cron jobs to regularly update GitHub analytics, language stats, and dynamic content.
- [ ] Introduce interactive visual elements (e.g., SVG animations or dynamic charts) reflecting my interests in Graphic Design and Theory discovery.
- [ ] Continuously update the Tech Stack icons and structure to reflect new skills and technologies learned over time, maintaining an up-to-date professional presence.
